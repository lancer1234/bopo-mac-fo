# 五分鐘上手

## 安裝

1. 在 [Release 頁](https://github.com/lancer1234/bopo-mac-fo/releases) 下載 `bopo-mac-fo-0.1.0-windows-x64.zip`，不是下方 GitHub 自動產生的 Source code。
2. 把 ZIP **全部解壓縮**到一個資料夾，再開啟 `Setup.exe`。
3. 保留預設的「保留其他輸入法」，或選「只使用 bopo MAC fo」。後者會停用微軟注音與新酷音，並把語言清單整理成只剩本輸入法。
4. 按「安裝」，自行確認 Windows 的管理員提示。第一次缺少 PIME 時，會從 EasyIME 官方 GitHub 下載前置元件，並核對檔案雜湊。
5. 完成後重新開啟瀏覽器、聊天程式或編輯器。必要時登出再登入，載入新元件。

![安裝選項](images/setup.png)

適用 Windows 10／11 x64。需以同一個 Windows 管理員帳號完成安裝，不能在權限提示中改成另一個帳號。Windows ARM64 尚未支援。

## 先試這幾個操作

- 用標準注音輸入「你」：按 `s`、`u`、`3`。游標在字後，按 ↓ 叫出候選框。
- 用數字選候選字。候選最後一格的 `ㄋㄧˇ` 可以把這個詞換成帶聲調注音；不會把它學成新的中文詞彙。
- 輸入 `s`、`u` 後直接 Enter，會保留 `ㄋㄧ`，不必先轉成中文字。
- 短按 CapsLock 切換中英。想打大寫時按住約半秒，達門檻時立即切換大小寫鎖定，再放開即可。
- Shift＋符號鍵使用鍵盤上方符號；Ctrl 的中文符號映射保留。

## 開啟表情面板

按 **Ctrl + Alt + E**。先點要輸入的編輯區，再點面板上的 emoji；可以把面板拖到旁邊、連續點選，然後接著打字。

- 「全部」有 3,944 項，包含膚色與多人／組合序列。「常用」保留 27 個快速選項。
- 搜尋框可輸入「貓」「開心」「愛心」或英文名稱；可在分類間切換。
- 用滑鼠滾輪或底部的 ‹ › 換頁。右上 × 或快捷鍵可隱藏面板。
- 登入時面板在背景等待快捷鍵，不會自動彈出。

![表情圖庫](images/emoji.png)

圖庫預覽採 Fluent Emoji；貼進程式後，會由該程式決定圖案、字型和顏色。舊式文字框可能顯示黑白，傳到手機後則由手機的 emoji 系統繪製。輸入的是標準文字，不是圖片貼紙。

## 設定與資料在哪裡？

| 內容 | 位置 |
|---|---|
| 個人注音設定與詞庫 | `%APPDATA%\PIME\mcbopomofo\` |
| 本版安裝紀錄與原設定備份 | `%LOCALAPPDATA%\bopo-mac-fo\` |
| 安裝紀錄 | `%LOCALAPPDATA%\bopo-mac-fo\setup.log` |
| 面板與 CapsLock 輔助程式 | `%ProgramFiles(x86)%\PIME\bopo-mac-fo\` |

這個預覽版沒有額外的圖形化設定頁。若需進階修改，先備份 `config.json`，再編輯設定。不要刪除同資料夾內的個人詞庫。

## 解除安裝與回復

在 Windows「設定 → 應用程式 → 已安裝的應用程式」找到 **bopo MAC fo**，選解除安裝，並確認管理員提示。

解除安裝會停止輔助程式，還原安裝前的 PIME 後端、原生服務、注音設定、輸入法清單和啟動項目。個人詞庫與備份保留，PIME 前置元件不會一併移除。

已開啟的程式仍可能載入舊 DLL，請重新登入。為了避免刪到共用 PIME 元件，預覽版暫時保留程式檔；確認已回復、重新登入後，可只刪除 `%ProgramFiles(x86)%\PIME\bopo-mac-fo\` 與 `x64`／`x86` 裡本版的 `BopoMacFo-0.1.0.dll`。**不要刪除整個 PIME 資料夾或個人詞庫。**

若安裝失敗，安裝器會嘗試依備份回復，詳細訊息記在 `setup.log`。回報問題時只提供必要錯誤段落，先遮住帳號、私人路徑或輸入內容。

## 常見問題

**候選框看起來還是舊版？** 關閉後重開目前程式；仍不更新時重新登入。

**CapsLock 或 emoji 快捷鍵沒作用？** 檢查工作管理員是否有 `CapsSwitch.exe`、`EmojiPalette.exe`，以及 Windows「啟動應用程式」中的 BopoMacFo 項目是否啟用。也可手動從上述安裝目錄啟動它們。Ctrl + Alt + E 若已被別的程式占用，面板會顯示提示。

**為什麼其他輸入法還在？** 預設會保留其他輸入法。選「只使用 bopo MAC fo」才會停用它們；Windows 有時要重新登入才刷新切換清單。

**能讓所有程式都變成 iOS emoji 嗎？** 無法靠輸入法統一控制。此版本沒有安裝或替換 Apple 字型。

**和原版小麥的選字排序完全相同嗎？** 使用 McBopomofoWeb 自己的語言模型與學習狀態，可能與 macOS 版本不同。

**能在系統管理員程式裡點 emoji 嗎？** 一般權限的面板無法替管理員權限程式注入輸入；建議在一般權限程式使用，勿為此關閉系統防護。
